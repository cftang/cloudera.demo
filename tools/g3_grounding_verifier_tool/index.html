    G3 — Grounding Verifier Tool¶

    File Download
    Tool source g3_grounding_verifier_tool.py
    Dependencies requirements.txt

    The G3 Grounding Verifier Tool (g3_grounding_verifier_tool.py) is the verification centrepiece, used by the dedicated Grounding Verifier agent. It takes the investigator's claims[] plus an independent evidence_bundle and judges each claim supported / partial / conflicting / unsupported, then aggregates a workflow response_policy. By design it sees only atomic claims + independent evidence (never the upstream reasoning prose) to avoid confirmation bias.

    Modes¶

    Mode Use Behaviour
    local POC Deterministic rule check, no network: a claim is supported only if its source_id points at an authoritative (allowlisted-prefix), RELEASED doc or a real data row; DOC-GEN-* / unsourced / stale → unsupported
    api Production POST {claims, evidence_bundle} to a hosted grounding model on Cloudera AI Inference; verdicts passed through

    response_policy aggregation¶

    any conflicting → present_conflict · all supported → answer_with_citations · some supported/partial → answer_supported_only · none → abstain. needs_clarification=true short-circuits to abstain.

    UserParameters¶

    Parameter Type Default Description
    mode str local local (rule) or api (hosted model)
    authoritative_prefixes list[str] ["SOP-","COA-","ECN-","DRW-","SPEC-","WPS-"] A source_id is authoritative only with one of these prefixes
    generic_prefixes list[str] ["DOC-GEN-"] Distractor prefixes → unsupported
    require_released bool true An authoritative doc must also be in evidence_bundle.released_docs/authoritative_docs
    verifier_endpoint str? None AI Inference base URL (required when mode='api')
    verifier_api_key str? None Bearer token for the AI Inference endpoint

    ToolParameters¶

    Parameter Type Description
    claims list[dict] [{claim, source_ids, confidence}]
    evidence_bundle dict {authoritative_docs[], released_docs[], conflicts[[a,b]], needs_clarification}
    action_on_block str return_verdict (default) or raise_error (halts on response_policy=abstain)

    Response format¶

    {
  "guardrail": "G3",
  "verdicts": [{"claim": "…", "status": "unsupported", "source_ids": [], "reason": "…"}],
  "response_policy": "abstain",
  "dropped_claims": ["…"],
  "citations": []
}

    Registering in the Tools Catalog¶

    1. Download g3_grounding_verifier_tool.py and requirements.txt above; upload both to your CAI project under g3_grounding_verifier/ (rename the Python file to tool.py if required).
    2. Install dependencies: pip install -r g3_grounding_verifier/requirements.txt.
    3. In Agent Studio, Tools Catalog → Add Tool, point at the g3_grounding_verifier/ folder.
    4. For the POC keep mode=local (defaults work). For production set mode=api and fill verifier_endpoint / verifier_api_key. Attach the tool to the Grounding Verifier agent.
